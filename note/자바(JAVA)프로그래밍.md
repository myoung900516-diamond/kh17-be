# 자바(JAVA)프로그래밍
- 자바라는 언어를 사용하여 프로그램을 만드는 것
- 프로그램이란 실행이 가능한 파일들의 모음을 말한다.
- 프로그램을 실행시켜서 사람이 하기 귀찮거나 어려워서 못하는 것들을 대신 해달라고 부탁
- 프로그래밍 언어마다 특색이 존재한다
- 처리 방식에 따라 구분 : 컴파일러방식(녹화방송) , 인터프리터방식(생방송)
- 운영체제와의 관계에 따라 구분 : 종속적(한명이랑만 친한) , 독립적(전부다 안친한)
- 자바는 컴파일러 방식이면서, 가상머신(에뮬레이터)을 이용한 독립적인 구조를 가진다
- 자바의 가상머신을 JVM(Java Virtual Machine)이라고 부르며, 컴파일러와 합쳐서 JDK(Java Development Kit)라 부른다
- amazon corretto는 아마존 이라는 회사에서 배포하는 JDK이다.
