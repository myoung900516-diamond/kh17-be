# 리스트(list)

번호를 붙이거나, 점 표시를 해서 항목을 정리할 때 사용

### 앞으로 배울 내용들
- 프론트엔드
- 백엔드
- 인프라
- 데이터베이스

### Github 가입순서
1. 가입버튼을 누른다
2. 정보를 입력한다
3. 캡챠 퀴즈를 푼다
4. 인증번호를 입력한다
5. 가입을 완료한다

# 링크(link)

클릭을 통해 다른 페이지로 이동할 수 있는 글자를 만들 수 있다. 
네이버로 이동하시려면 [여기](https://www.naver.com/)를 누르세요. 

```
[보여줄글자](이동할주소)
```


# 이미지(image)

이미지를 문서에 넣을 수 있다. 

```
![설명;이미지가 안나올 때 나올 글자](이미지주소)
```
